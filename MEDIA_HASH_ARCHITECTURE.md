# Архитектура системы автоматического хэширования медиафайлов

## Общая схема работы

```
┌─────────────────────────────────────────────────────────────────┐
│                    ЗАГРУЗКА МЕДИАФАЙЛА                          │
│                                                                 │
│  Способы загрузки:                                             │
│  • WordPress Media Library (стандартный интерфейс)             │
│  • Media Sync плагина                                          │
│  • WP-CLI (wp media import)                                    │
│  • REST API                                                    │
│  • Любой код, использующий wp_insert_attachment()             │
└──────────────────────┬──────────────────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────────────────┐
│              WORDPRESS CORE PROCESSING                          │
│                                                                 │
│  1. Файл загружается в uploads directory                       │
│  2. Создаётся attachment post                                  │
│  3. Генерируются thumbnails (для изображений)                  │
└──────────────────────┬──────────────────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────────────────┐
│                    HOOKS TRIGGERED                              │
│                                                                 │
│  ┌──────────────────────────────────────────────┐              │
│  │ wp_generate_attachment_metadata (filter)     │              │
│  │ • Для файлов с метаданными (изображения)    │              │
│  │ • Priority: 10                               │              │
│  └───────────────────┬──────────────────────────┘              │
│                      │                                          │
│                      ▼                                          │
│         Media_Hash::add_hash_to_attachment()                   │
│                      │                                          │
│  ┌──────────────────────────────────────────────┐              │
│  │ add_attachment (action)                      │              │
│  │ • Fallback для файлов без метаданных         │              │
│  │ • PDF, DOC, ZIP и т.д.                       │              │
│  └───────────────────┬──────────────────────────┘              │
│                      │                                          │
│                      ▼                                          │
│      Media_Hash::add_hash_to_attachment_fallback()             │
└──────────────────────┬──────────────────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────────────────┐
│              HASH CALCULATION & STORAGE                         │
│                                                                 │
│  1. Получить путь к файлу: get_attached_file($id)             │
│  2. Проверить существование файла                              │
│  3. Вычислить MD5: $hash = md5_file($path)                    │
│  4. Сохранить метаданные:                                      │
│     • aie_file_hash = [MD5 хэш]                               │
│     • aie_file_size = [размер в байтах]                       │
│     • aie_hash_added = [текущая дата/время]                   │
└─────────────────────────────────────────────────────────────────┘
```

┌────────────────────────────────────────────────────────────────┐

                  ┌──────────────────────┐
                  │  Есть файлы?         │
                  └──────┬───────────────┘
                         │
                    ┌────┴────┐
                    │         │
                   Да        Нет
                    │         │
                    ▼         ▼
        ┌──────────────────────────┐      ┌────────────┐
        │  Цикл по каждому файлу:  │      │  Return:   │
        │                          │      │  processed │
        │  foreach ($attachments)  │      │  = 0       │
        │  {                       │      └────────────┘
        │    1. get_attached_file()│
        │    2. file_exists()?     │
        │    3. md5_file()         │
        │    4. update_post_meta() │

        ┌──────────────────────┐

## Интеграция с Media Sync

```
┌────────────────────────────────────────────────────────────────┐
│                    Media Sync Import Process                    │
└────────────────────────────┬───────────────────────────────────┘
                             │
                             ▼
┌────────────────────────────────────────────────────────────────┐
│  Media_Sync::import_file($path, $options)                      │
│                                                                │
│  1. Проверка типа файла                                        │
│  2. Проверка дубликатов (если включено):                       │
│     if ($options['skip_duplicates']) {                         │
│       $duplicate = check_duplicate_by_hash($path);  ◄─┐       │
│       if ($duplicate) return WP_Error;                 │       │
│     }                                                  │       │
│  3. Копирование/перемещение файла                      │       │
│  4. wp_insert_attachment()                             │       │
│  5. wp_generate_attachment_metadata() ◄────────────────┼───┐   │
│  6. update_post_meta('aie_file_hash', ...)  ◄──────────┘   │   │
└────────────────────────────────────────────────────────────┼───┘
                                                             │
┌────────────────────────────────────────────────────────────┘
│  Media_Hash хуки ТАКЖЕ срабатывают автоматически:
│
│  wp_generate_attachment_metadata hook
│     → Media_Hash::add_hash_to_attachment()
│         → update_post_meta('aie_file_hash', ...)
│
│  Результат: хэш добавляется ДВАЖДЫ (защита от ошибок):
│    1. Явно в Media_Sync::import_file()
│    2. Автоматически через Media_Hash хуки
└────────────────────────────────────────────────────────────────┘
```

## Безопасность и валидация

```
┌────────────────────────────────────────────────────────────────┐
│                    AJAX Request                                 │
└────────────────────────────┬───────────────────────────────────┘
                             │
                             ▼
┌────────────────────────────────────────────────────────────────┐
│  1. Nonce Verification                                         │
│     verify_request('action_name')                              │
│     • wp_verify_nonce()                                        │
│     • Защита от CSRF                                           │
└────────────────────────────┬───────────────────────────────────┘
                             │
                             ▼
┌────────────────────────────────────────────────────────────────┐
│  2. Capabilities Check (в Base_Controller)                     │
│     current_user_can('manage_options')                         │
└────────────────────────────┬───────────────────────────────────┘
                             │
                             ▼
┌────────────────────────────────────────────────────────────────┐
│  3. Path Validation (если передан путь)                        │
│     $real_path = realpath($file_path);                         │
│     $real_base = realpath($uploads['basedir']);                │
│     if (strpos($real_path, $real_base) === false) {            │
│       return WP_Error('invalid_path');                         │
│     }                                                           │
└────────────────────────────┬───────────────────────────────────┘
                             │
                             ▼
┌────────────────────────────────────────────────────────────────┐
│  4. Input Sanitization                                         │
│     $batch_size = absint($input);                              │
│     $batch_size = min($batch_size, 100); // limit             │
└────────────────────────────┬───────────────────────────────────┘
                             │
                             ▼
┌────────────────────────────────────────────────────────────────┐
│  5. Execute Action                                             │
│     (безопасно выполнить запрошенное действие)                 │
└────────────────────────────────────────────────────────────────┘
```
