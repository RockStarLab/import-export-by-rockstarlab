# Content Updater - Filters Step Added

## Изменения

Добавлен новый шаг 2 "Filters" между выбором контента и выбором полей.

### Новая структура шагов:

**Шаг 1:** Выбор типа контента (Pages, Posts, Users, etc.)
**Шаг 2:** Фильтры (НОВЫЙ) - опционально, можно пропустить
**Шаг 3:** Выбор полей для обновления (post_title, post_content, etc.)
**Шаг 4:** Назначение функций (uppercase, lowercase, etc.)
**Шаг 5:** Запуск обновления

### Базовые фильтры (уже добавлены в UI):

- **Post Status**: выбор статусов (Published, Draft, Pending, Private, Trash)
- **Author**: фильтр по автору
- **Date Range**: фильтр по дате публикации (от - до)

### Логика работы:

1. Пользователь выбирает тип контента (например, Pages)
2. (НОВОЕ) Пользователь опционально применяет фильтры (например, только Published pages)
3. Пользователь выбирает поля для обновления (например, post_title)
4. Пользователь назначает функции (например, uppercase)
5. Система получает отфильтрованные записи и обновляет только их

### Использование:

После обновления фильтры автоматически появятся на шаге 2. Если пользователь не хочет фильтровать, он просто нажимает "Next" и обновятся все записи выбранного типа.

Если пользователь выбирает фильтры (например, только Published pages от автора John), то обновятся только те записи, которые соответствуют фильтрам.
