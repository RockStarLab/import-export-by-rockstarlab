Workflows that match real projects

From “move content once” to “keep sites in sync” — choose the path that fits.

  1. Select content type (posts, CPT, users, WooCommerce, or raw tables).
  2. Upload CSV (delimiter support + streaming for large files).
  3. Preview & map fields with validation.
  4. Transform values using PHP functions when needed.
  5. Run in background and review results in Jobs Log.
Import documentation
  1. Pick a dataset (content types or raw MySQL tables).
  2. Filter precisely by IDs, date ranges, authors, taxonomies, statuses.
  3. Select fields to keep exports lean and useful.
  4. Export to CSV (or JSON) for backups, analysis, or migrations.
  5. Rerun anytime from Jobs Log with one click.
Export documentation
  1. Connect sites using secure API keys.
  2. Choose direction: pull from remote or push to it.
  3. Sync selectively by filters — not everything, only what you need.
  4. Resolve conflicts with skip/update/duplicate strategies.
  5. Include media so attachments arrive with content.
Sync documentation
  1. Filter records (date, status, taxonomy, author, IDs).
  2. Select fields you want to change.
  3. Apply functions to transform values (string, HTML, date, WP helpers).
  4. Preview changes before executing.
  5. Execute and track everything in Jobs Log.
Updater documentation

Pro tip: these workflows can modify lots of records quickly. Always take a full backup before big imports or bulk updates.

Frequently asked questions

Quick answers to common questions from users and developers.

Where is the plugin documentation?
The online docs live at wpimportexport.com/docs.
Can I import large CSV files into WordPress without timeout issues?
Yes — the plugin uses background processing and CSV streaming to handle files with hundreds of thousands of rows without hitting PHP timeout limits.
Does it support WooCommerce import and export?
Yes. You can import and export WooCommerce products, product variations, orders, and coupons — including all custom meta and attributes.
Can I import and export ACF (Advanced Custom Fields) data?
Yes. ACF fields are fully supported for both import and export across all field types, including repeaters and flexible content.
Can I transform data during import?
Yes. Use the built-in Functions Library to write custom PHP transformations for any mapped field. Functions are reusable across jobs.
How do I migrate content between two WordPress sites?
Use the Site-to-Site Sync feature. Connect sites with secure API keys, choose Push or Pull direction, filter what to sync, and optionally include media attachments.
Can I export WordPress posts to CSV or JSON?
Yes. Export any content type — posts, pages, custom post types, users, or raw MySQL tables — to CSV or JSON. Filter by date, status, author, taxonomy, or IDs.
How do I avoid importing duplicate media files?
Use Media Folder Sync with duplicate detection. Choose Hash (most accurate), Filename (fastest), or Filesize (balanced) as the detection strategy.
Is there a free version available?
Yes — the core plugin is free on WordPress.org. Premium plans unlock Content Sync, AI tools, and advanced features. New users get 1 free month of premium.
