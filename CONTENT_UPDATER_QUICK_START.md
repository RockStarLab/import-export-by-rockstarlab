# Content Updater - Quick Start Guide

## Что такое Content Updater?

Content Updater - это инструмент для массового обновления контента с применением пользовательских функций к выбранным полям. Он позволяет автоматизировать трансформацию данных без необходимости ручного редактирования каждого элемента.

## Быстрый старт

### Шаг 1: Выбор типа контента

1. Перейдите в **Advanced Import Export → Content Updater**
2. Выберите тип контента, который хотите обновить:
   - Blog Posts (Записи)
   - Pages (Страницы)
   - Media (Медиафайлы)
   - Users (Пользователи)
   - Comments (Комментарии)
   - Custom Post Types (Произвольные типы записей) - Premium
   - Taxonomy Terms (Термины таксономий) - Premium
   - WooCommerce Products/Orders/Coupons - Premium
3. Нажмите **Next Step**

### Шаг 2: Выбор полей

1. В правой панели отображаются доступные поля для выбранного типа контента
2. Выберите поля, которые хотите обновить:
   - **Перетащите** поля в левую панель (drag & drop), ИЛИ
   - **Кликните** на поле, чтобы добавить его
3. Используйте поиск для фильтрации полей
4. Нажмите **Next Step**

### Шаг 3: Назначение функций

1. Для каждого выбранного поля назначьте функцию трансформации
2. Выберите функцию из выпадающего списка
3. Опции:
   - **None** - поле будет пропущено
   - **Выберите функцию** из списка доступных функций
4. Используйте кнопку **Test** для проверки работы функции на тестовых данных
5. Дополнительные действия:
   - **Apply to All** - применить одну функцию ко всем полям
   - **Clear All** - очистить все назначения
6. Нажмите **Next Step**

### Шаг 4: Запуск обновления

1. Проверьте сводку обновления:
   - Тип контента
   - Количество элементов
   - Количество полей
   - Назначенные функции

2. Настройте параметры:
   - **Items per Iteration** (10-50 рекомендуется) - количество элементов, обрабатываемых за одну итерацию
   - **Test Mode (Dry Run)** - тестовый режим без сохранения изменений

3. **ВАЖНО**: Создайте резервную копию базы данных перед запуском!

4. Нажмите **Start Update**

5. Отслеживайте прогресс:
   - Прогресс-бар с процентами
   - Количество обработанных элементов
   - Количество обновленных элементов
   - Количество пропущенных элементов
   - Количество ошибок

6. Дождитесь завершения или нажмите **Cancel Update** для остановки

## Примеры использования

### Пример 1: Преобразование заголовков в верхний регистр

1. Выберите **Blog Posts**
2. Добавьте поле **post_title**
3. Назначьте функцию **"Convert to Uppercase"**
4. Запустите обновление

### Пример 2: Очистка HTML-тегов из описаний

1. Выберите **Blog Posts**
2. Добавьте поле **post_excerpt**
3. Назначьте функцию **"Strip HTML Tags"**
4. Сначала запустите в **Dry Run** режиме для проверки
5. Затем запустите реальное обновление

### Пример 3: Обновление нескольких мета-полей

1. Выберите **Blog Posts**
2. Добавьте мета-поля: **custom_field_1**, **custom_field_2**, **custom_field_3**
3. Назначьте разные функции для каждого поля
4. Запустите обновление с Items per Iteration = 20

## Рекомендации

### Перед обновлением

✅ **Создайте резервную копию базы данных**
✅ **Протестируйте функции** на небольшом наборе данных
✅ **Используйте Dry Run** для первого запуска
✅ **Проверьте функции** на корректность работы

### Во время обновления

- Начните с **малого размера батча** (10-20 элементов)
- Следите за **количеством ошибок** в процессе
- **Не закрывайте** страницу браузера во время обновления
- При высоком проценте ошибок - **остановите** процесс и проверьте функции

### После обновления

- Проверьте **результаты обновления** в базе данных
- Просмотрите **логи** для деталей (Advanced Import Export → Jobs Log)
- При необходимости **откатите** изменения из резервной копии

## Ограничения

- **Timeout**: Для очень больших наборов данных уменьшите размер батча
- **Memory**: При работе с большими объемами памяти - используйте меньший батч
- **Database Tables**: Прямое обновление таблиц БД пока не реализовано
- **Премиум-функции**: Некоторые типы контента доступны только в Premium версии

## Устранение неполадок

### Высокий процент ошибок
- Проверьте код функций на ошибки
- Убедитесь, что имена полей указаны правильно
- Проверьте логи сервера

### Медленная обработка
- Уменьшите размер батча
- Оптимизируйте код функций
- Проверьте ресурсы сервера

### Timeout ошибки
- Уменьшите Items per Iteration
- Увеличьте PHP max_execution_time
- Свяжитесь с хостингом для настройки лимитов
