# Import Export by RockStarLab

Import, export, and sync WordPress content using CSV, XML, XLSX, ODS, and JSON.

## Features

- Import and export content with field mapping.
- Sync posts, pages, and media between WordPress sites.
- Process imports and exports in background jobs.
- Import content from public URLs with your own OpenAI API key.
- Extend supported content types and migration tools with the optional PRO addon.

## Installation

1. Download and extract the plugin archive.
2. Copy the plugin to `wp-content/plugins/import-export-by-rockstarlab`.
3. Activate it in the WordPress Plugins screen.

See [readme.txt](readme.txt) for requirements, release notes, and external service details.
