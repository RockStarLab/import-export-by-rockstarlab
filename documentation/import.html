📥 Importing Data

Import posts, pages, custom post types, users, WooCommerce products, and any MySQL table data from CSV files.

Supported Content Types

  • Posts, Pages, and Custom Post Types (CPTs)
  • Taxonomies and Terms
  • Users and User Meta
  • Comments
  • Navigation Menus
  • Raw MySQL Tables
  • WooCommerce Products, Variations, Orders, Coupons Pro
  • Advanced Custom Fields (ACF) Pro
  • Yoast SEO Meta Pro

Supported File Formats

  • CSV — Standard comma-separated values with streaming support for large files
ℹ️ JSON Format
JSON is currently supported for export only. To import data that is currently in JSON format, convert it to CSV first.

Import Workflow

Step 1 — Open the Import Screen

Navigate to Import Export → Import in the WordPress admin sidebar.

Step 2 — Choose Content Type & Upload File

Select the Import Type (e.g., Posts, Users, MySQL Table) from the dropdown. Then drag-and-drop your CSV file onto the upload area, or click Browse to pick a file. The plugin supports chunked uploads so very large files will not time out.

Step 3 — Preview the Data

After uploading, the plugin parses the first five rows and shows a preview table. Verify that the data looks correct before proceeding to field mapping.

Step 4 — Map Fields

Map each column in your CSV to the corresponding WordPress field. The plugin automatically suggests mappings based on column names. You can also assign a custom function to any field to transform the value during import.

Available WordPress Fields (Posts)

FieldDescription
post_titleTitle of the post
post_contentMain body content (HTML supported)
post_excerptShort description / excerpt
post_statuspublish, draft, private, pending…
post_datePublication date (Y-m-d H:i:s)
post_authorAuthor login or ID
post_nameURL slug
post_parentParent post ID (for pages & CPTs)
featured_imageURL or file path to the featured image
taxonomiesCategory, tag, or custom taxonomy values
meta_*Any post meta key (e.g., meta_price)

Step 5 — Set Import Options

Before starting, configure the advanced import options:

OptionDescription
Duplicate Strategy How to handle records that already exist: Skip (do nothing), Update (overwrite existing fields), or Duplicate (create a new record regardless).
Duplicate Detection Key The field used to identify duplicates (e.g., post_title, ID, or any meta key).
Default Post Status Fallback status when the CSV row does not include a post_status column.
Import Images When enabled, the plugin downloads and attaches images found in the featured_image column or inside post content.
Batch Size Number of rows to process per background batch. Lower values reduce memory usage on shared hosts.
Send Email Notification Sends an email to the admin when the import finishes.

Step 6 — Run the Import

Click Start Import. The plugin creates a Job and begins processing in the background using WordPress cron. A real-time progress bar shows rows processed, successes, and errors.

💡 Re-run a Job
Every import is saved in the Jobs Log. You can re-run it at any time with one click — no need to re-upload the file or reconfigure settings.

Importing Raw MySQL Tables

Select MySQL Table as the import type. The plugin will ask you to choose the target table and then map your CSV columns to the table columns. This is useful for migrating custom plugin data, e-commerce orders, or any non-standard data.

⚠️ Warning
Writing directly to database tables can cause data integrity issues. Always create a full database backup before running a raw MySQL import.

CSV File Requirements

  • Encoding: UTF-8 (BOM optional)
  • Delimiter: comma , or semicolon ; (auto-detected)
  • First row must be a header row with column names
  • Dates should be formatted as Y-m-d or Y-m-d H:i:s
  • For multiple taxonomy values in one cell, separate them with a pipe |
