🔑 License Activation

Activate your Premium licence to unlock Custom Post Types support, WooCommerce support, ACF integration, Real Media Library sync, and more.

Premium Features

The following features are exclusive to the Premium (paid) plan:

  • 📦 Import & Export — Custom Post Types, Media, Menus, Users, Comments, Taxonomy Terms, WooCommerce Products, Attributes, Coupons and Orders, and any MySQL Database Table
  • 🔄 Content Sync — Sync selected Posts or Pages between different sites (e.g. Production & Staging)
  • ✏️ Content Updater — Bulk-update post fields across your entire site using custom transformation functions
  • 🤖 AI URL Importer — Automatically import content from any URL into any post type using AI
  • 🧠 AI Functions Generator — Describe a data transformation in plain English and let AI write the PHP function for you
🎉 Free Trial
All new installations automatically receive a 4-week free trial of all Premium features. Get your promo code at the Plugin's Dashboard and use it during checkout.

Purchase your licence

Licence management is handled through Freemius — a trusted platform for WordPress plugin licensing.

If you are a new user and want to purchase a Premium licence, follow these steps:

  1. 1
    Purchase a Premium licence
    Visit the WP Advanced Import Export -> Upgrade link and choose your plan.
  2. 2
    Fill the payment details
    Add your card details and complete the checkout process. After successful payment license will be activated automatically and you can start using Premium features right away.
  3. 3
    Promo code
    If you have a promo code, click the Have a promo code? link on the checkout page, enter your code, and click Apply.

Activating existing licence

If you are an existing user and need to activate your licence, follow these steps:

  1. 1
    Navigate to the Plugins screen
  2. 2
    Find WP Advanced Import Export in the list of installed plugins.
  3. 3
    Click the Activate License link below the plugin name.
  4. 4
    Enter your licence key, and click Activate.

Managing Your Account

After activation, you can manage your subscription from WP Advanced Import Export → Account. From there you can:

  • View your current plan and expiry date
  • Transfer the licence to a different site
  • Deactivate the licence to free up a site slot
  • Upgrade or renew your plan
ℹ️ Licence Deactivation
If you are moving your site to a new domain, deactivate the licence on the old site first (Account → Deactivate Licence), then activate it on the new domain. This prevents using multiple site slots unintentionally.
⚠️ Expired Licences
When a Premium licence expires the plugin continues to work, but Premium features will be disabled until you renew. Your data and settings are never deleted.
