📤 Exporting Data

Export any WordPress content type, custom fields, or raw database table to CSV or JSON — with powerful filters and field selection.

Supported Export Types

  • Posts, Pages, and any Custom Post Type
  • Taxonomies and Terms
  • Users and User Meta
  • Comments
  • Navigation Menus
  • Raw MySQL Tables
  • WooCommerce Products (including variations), Orders, Coupons, Attributes Pro

Output Formats

  • CSV — Compatible with Excel, Google Sheets, and other import tools
  • JSON — Suitable for developer workflows and API integrations

Export Workflow

Step 1 — Open the Export Screen

Navigate to Import Export → Export in the WordPress admin sidebar.

Step 2 — Select Export Type

Choose the content type you want to export from the Export Type dropdown. After selecting a type, the available filter and field options will update dynamically.

Step 3 — Filter Records

Narrow down which records to export using the filter panel. Available filters depend on the export type.

FilterDescription
Post Status Export only published, draft, pending, or private posts.
Date Range Filter by post_date — export posts from a specific period.
Author Export posts by a specific author.
Taxonomy / Category Limit to posts in a specific category, tag, or custom taxonomy term.
Post IDs Manually enter specific post IDs to export only those records.
Custom Field Filter Filter by any meta key/value pair (e.g., export only products with _stock_status = instock).

The Count button shows how many records match your current filters before you start the export.

Step 4 — Select Fields to Export

Choose which fields to include in the output. By default, all standard fields are selected. You can add custom meta fields, ACF fields, or Yoast SEO fields using the field picker.

Step 5 — Configure Export Options

OptionDescription
Output Format CSV or JSON.
CSV Delimiter Comma , or semicolon ;.
Include Header Row Adds a header row with field names as the first line of the CSV.
Batch Size Number of records to process per background batch.
Apply Functions Assign a custom function to transform field values before they are written to the file.
Send Email Notification Sends a download link to the admin email when the export finishes.

Step 6 — Run the Export & Download

Click Start Export. The plugin creates a Job and processes the export in the background. When complete, a Download File button appears. The file link is also available in the Jobs Log for later retrieval.

💡 Large Exports
Exports of tens of thousands of rows are handled efficiently using streaming. The file is written in batches, so your server will never run out of memory regardless of the dataset size.

Exporting Raw MySQL Tables

Select MySQL Table as the export type, then choose the target table from the list of all tables in your database. You can select which columns to include and apply filters by any column value. This is especially useful for exporting custom plugin data or logs.

Secure Download Links

All exported files are stored in a protected upload directory. Download links are time-limited and require authentication, preventing unauthorised access to potentially sensitive data.
