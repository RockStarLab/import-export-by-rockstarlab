Welcome to Advanced Import Export

The ultimate toolkit for managing, migrating, and synchronising WordPress data with precision and power.

Advanced Import Export is a comprehensive plugin built for developers and store owners who need complete control over their WordPress data. Whether you are migrating a website, synchronising content between staging and production, performing bulk updates, or organising FTP-uploaded media, this plugin provides a robust and flexible framework to handle even the most complex datasets.

What Can You Do With This Plugin?

📥

Import Data

Import posts, pages, CPTs, users, media, WooCommerce products and more from CSV files.

📤

Export Data

Export any content type or raw MySQL table to CSV or JSON with powerful filters.

🔄

Content Sync

Connect two WordPress sites via API and sync posts, pages, and media bidirectionally.

✏️

Bulk Updater

Apply PHP transformations to fields across thousands of posts without a single SQL query.

🖼️

Media Library Sync

Scan server folders and register SFTP-uploaded files into the WordPress Media Library.

🤖

AI URL Importer

Provide a URL and let AI parse the remote page and create a post of any type automatically.

⚙️

Functions Library

Write and reuse custom PHP transformation functions with a built-in code editor and 50+ examples.

📋

Jobs Log

Every import, export, or sync is saved so you can re-run or review any job in one click.

Supported Data Types

  • WordPress Core: Posts, Pages, Custom Post Types, Taxonomies, Terms, Navigation Menus, Comments, Users
  • WooCommerce: Products (including variations), Attributes, Orders, Coupons
  • Advanced Custom Fields (ACF): Full field support during import & export
  • Yoast SEO: All SEO meta fields
  • MySQL: Any database table in your WordPress database
