Introduction

WP Advanced Import Export is a powerful WordPress plugin for professional data import, export, and synchronization operations.

Key Features

📥 Import/Export

CSV, JSON, XML support with streaming for large files

🔄 Synchronization

Sync content between sites and media from FTP folders

⚡ Performance

Background processing without memory limits

🎯 Field Mapping

Intuitive field mapping with preview

🛠️ Custom Functions

Transform data with 50+ ready-made PHP functions

🤖 AI Integration

Auto content extraction and function generation

Who Is This For?

  • Web Developers — site migrations and bulk operations
  • Content Managers — managing large content volumes
  • Agencies — syncing across multiple client sites
  • E-commerce Owners — product catalog management
  • SEO Specialists — bulk metadata updates
💡 Tip: Start with "Quick Start" to learn the main features.

Installation

Method 1: WordPress Admin

  1. Go to Plugins → Add New
  2. Search for "WP Advanced Import Export"
  3. Click Install then Activate
Screenshot: Plugin installation

Method 2: Upload ZIP

  1. Download plugin ZIP
  2. Go to Plugins → Add New → Upload
  3. Choose ZIP file and install

Method 3: FTP

  1. Extract ZIP archive
  2. Upload folder to /wp-content/plugins/
  3. Activate via Plugins menu
✅ Done! Plugin is ready. See "Quick Start".

Quick Start

Your First Import

Step 1: Prepare CSV File

title,content,status,author
"My First Post","Post content here","publish","admin"
"Draft Post","Another post","draft","editor"

Step 2: Upload File

  1. Go to Import/Export → Import
  2. Click Choose File
  3. Select type: Posts, format: CSV
  4. Click Next
Screenshot: File upload

Step 3: Map Fields

  • title → Post Title
  • content → Post Content
  • status → Post Status
  • author → Post Author
Screenshot: Field mapping

Step 4: Start Import

  1. Review preview
  2. Click Start Import
  3. Wait for completion
🎉 Success! Your first import is complete.
