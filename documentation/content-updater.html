✏️ Content Updater

Apply bulk transformations to post fields across hundreds or thousands of records — without touching a single SQL query.

What is the Content Updater?

The Content Updater lets you select a content type, filter which records to target, choose specific fields, and then apply PHP transformation functions to each field value. All changes are processed in the background in batches, so even very large sites are handled safely.

Example use cases:

  • Convert all post titles to Title Case
  • Replace an old domain URL with a new one inside post content
  • Strip HTML tags from a custom meta field across all products
  • Set a default value for a missing meta field on all draft posts
  • Format all phone numbers stored in user meta to a consistent pattern

Update Workflow

Step 1 — Open the Content Updater

Navigate to Import Export → Content Updater.

Step 2 — Select Content Type

Choose the content type you want to update from the dropdown (e.g., Post, Page, Product, User). The available field options will update accordingly.

Step 3 — Apply Filters

Use the filter panel to narrow down which records will be affected. The same filtering options as the Export feature are available:

  • Post status
  • Date range (created or modified)
  • Author
  • Taxonomy / category
  • Specific post IDs
  • Custom meta field value

Click Count to see how many records match your filters before proceeding.

Step 4 — Select Fields and Assign Functions

Choose one or more fields to update. For each field, assign a transformation function that will be applied to the current value.

💡 Using the AI Function Generator
Not sure how to write the transformation you need? Open the Functions Library, click Generate with AI, and describe the transformation in plain English. The AI will write the PHP function for you.

Step 5 — Preview Changes

Click Preview to see a side-by-side comparison of the current value and the transformed value for the first few records. This lets you confirm the function behaves as expected before applying it to the full dataset.

Step 6 — Run the Update

Click Start Update. The plugin creates a background Job and processes the records in batches. A real-time progress bar shows the number of records updated, skipped, and any errors.

Available Updatable Fields

CategoryFields
Post Core post_title, post_content, post_excerpt, post_status, post_name, post_date
Post Meta Any custom meta key registered on the selected post type
User Core user_email, display_name, first_name, last_name
User Meta Any user meta key
ACF Fields All registered ACF fields for the selected post type Pro
⚠️ This Action Cannot Be Undone Automatically
Always back up your database before running a bulk update. While the Jobs Log records what was done, automatic rollback is not available. Use the Preview step to validate your function first.
